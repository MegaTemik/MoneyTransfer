# MoneyTransfer

Программа, которая показывает пример пополнения и снятия средств с баланса пользователей.

## Описание

Пользователь может запустить программу и увидеть пример пополнения и снятия баланса у 3-ех человек.

## Возможности

- 3 юзера
- Пополнение средств на баланс и снятие с баланса каждого юзера
- Вывод в консоль информации о 3-ех юзерах после операций

## Установка

```bash
git clone https://github.com/MegaTemik/MoneyTransfer
cd MoneyTransfer
```

## Запуск

```bash
go run main.go
```
