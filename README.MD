# MoneyTransfer

Программа, которая показывает пример пополнения и снятия средств с баланса пользователей, а также перевод другому пользователю.

## Описание

Пользователь может запустить программу и увидеть пример перевода со счета одного юзера на счет другого.

## Возможности

- 3 юзера
- Пополнение средств на баланс и снятие с баланса каждого юзера
- Перевод средств со счета одного юзера на счет другого
- Обработка ошибок на недостаточность средств на балансе юзера
- Вывод в консоль информации о 3-ех юзерах после операций
- Обработка 3-х операций одновременно горутинами
